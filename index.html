Agentic AI System Design

Schema-Enforced Tool Calling vs. Open-Ended LLM Generation

Implemented in: Agentic FPL Manager

In multi-variable tactical domains like Fantasy Premier League, open-ended LLM prompting introduces non-deterministic hallucinations in point calculations, budget constraints, and squad formation legality.

Solution: Enforced strict JSON Schema tool definitions via Google Gemini. The agent cannot guess points or valid transfers; it dynamically queries deterministic backend functions (verifying squad limits of max 3 players per club and exact bank thresholds) before returning conversational advice.

Scoring Engine EdTech Math

Domain-Weighted Readiness Model vs. Flat Percentages

Implemented in: AzureVibe

Standardized exams like Microsoft AZ-900 apply domain-weighted passing thresholds. Flat scoring creates false readiness confidence if students master easy cloud concepts while failing heavily weighted architecture services.

Solution: Formulated an exam-calibrated composite readiness algorithm: (0.28 × Concepts) + (0.37 × Architecture) + (0.35 × Governance) scaled to 1000 with a 700-point passing indicator and instant distractor feedback.

Data Ingestion Performance & Limits

In-Memory TTL Caching for Rate Limit Mitigation

Implemented in: Football Wrapped

External sports APIs (Football-Data.org) impose strict request rate limits on free-tier access. Fetching live fixtures, standings, and top scorer leaderboards on every user navigation triggers HTTP 429 throttling.

Solution: Architected a 600-second in-memory cache leveraging Streamlit's @st.cache_data(ttl=600) with competition-specific cache keys. This ensures zero redundant network calls on tab switching while keeping match results within a 10-minute freshness window.
